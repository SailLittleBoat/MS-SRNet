# MS-SRNet

This is the companion repository for the manuscript *An Electronic Nose Drift Compensation Algorithm Based on a Dual-Branch Representation Network with Label-Free Target Adaptation*.

The full source code and materials for reproducing the experiments will be released in this repository upon acceptance of the manuscript.

## Planned Repository Layout

- `Long-term/` will contain the code for the long-term drift experiments under the fixed-source protocol.
- `Short-term/` will contain the code for the short-term drift experiments under the expanding-source protocol.
